
# Stock Portfolio Tracker

## Project Description
This is a simple Python-based Stock Portfolio Tracker.

It calculates the total investment based on
manually entered stock prices and quantities.

## Features
- Add stock names
- Enter stock prices manually
- Enter number of shares
- Calculate individual investment
- Calculate total investment

## Technologies Used
- Python
- Dictionaries
- For Loops
- User Input

## How to Run
1. Download the Python file.
2. Open Python IDLE or VS Code.
3. Run stock_tracker.py.
4. Enter stock details.

## Example
TCS Price = 3500
Quantity = 2

Investment = 7000




## Sample Input

How many stocks do you want to add? 3

Enter stock name: TCS
Enter stock price: 3500
Enter number of shares: 2

Enter stock name: INFOSYS
Enter stock price: 1500
Enter number of shares: 3

Enter stock name: RELIANCE
Enter stock price: 2500
Enter number of shares: 1

## Sample Output

----- STOCK PORTFOLIO -----

TCS = 7000.0
INFOSYS = 4500.0
RELIANCE = 2500.0

---------------------------
Total Investment = 14000.0

## Calculation

TCS = 3500 * 2 = 7000
INFOSYS = 1500 * 3 = 4500
RELIANCE = 2500 * 1 = 2500

Total Investment = 14000
